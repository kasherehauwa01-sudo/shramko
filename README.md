# План питания Shramko

Статическая адаптивная версия НЕмарафона «Ешь. Худей. Люби.» для публикации на `https://kvasmix.ru/`. В странице собраны правила программы, меню на 20 дней и раздел с витаминами.

## Локальный запуск

```bash
python3 -m http.server 8080
```

После запуска страница доступна по адресу `http://localhost:8080`.

## Публикация на Timeweb

1. Откройте файловый менеджер панели Timeweb.
2. Перейдите в корневую папку сайта `kvasmix.ru` (обычно `public_html`).
3. Загрузите в неё `index.html`, `styles.css`, `script.js`, `yulia.jpeg` и папку `shramko-photos`.
4. Если в папке уже есть старый `index.html`, предварительно сохраните его резервную копию.

Сборка не требуется: сайт состоит из обычных HTML, CSS и JavaScript-файлов.

Отметки о съеденных блюдах и общий прогресс сохраняются локально в браузере пользователя.
